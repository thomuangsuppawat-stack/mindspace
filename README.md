# MindSpace (ฮีลใจ) 🌿
> **Digital Platform เพื่อการดูแลสุขภาวะทางจิตใจและการส่งต่อพลังใจในชุมชน**  
> *Project 15 คะแนน: การสร้าง Digital Platform แก้ปัญหาสังคม (กำหนดส่ง: 2 พ.ย. 69)*

---

## 📌 บทนำและความสำคัญของปัญหา (Problem Statement)
ในปัจจุบัน วัยรุ่น นิสิตนักศึกษา และคนวัยทำงานตอนต้น เผชิญกับสภาวะความเครียดสะสม อาการหมดไฟ (Burnout) และความเหงาโดดเดี่ยวในระดับสูงเป็นประวัติการณ์ ทว่าการเข้าถึงบริการทางจิตวิทยาในประเทศไทยยังมีอุปสรรคสำคัญ ได้แก่:
1. **ค่าใช้จ่ายสูง:** การพบนักจิตวิทยาหรือจิตแพทย์เอกชนมีค่าใช้จ่าย 1,500 – 3,000+ บาทต่อชั่วโมง
2. **คิวรอนาน:** สถาบันของรัฐมีจิตแพทย์ไม่เพียงพอต่อสัดส่วนประชากร
3. **การถูกตีตรา (Social Stigma):** หลายคนกังวล ไม่กล้าปรึกษาคนใกล้ชิดเพราะกลัวถูกตัดสินว่าเป็นคนอ่อนแอ

**MindSpace (ฮีลใจ)** จึงถูกพัฒนาขึ้นเป็น **Digital First-Aid & Peer Support Platform** ที่เปิดโอกาสให้ทุกคนเข้าถึงการเยียวยาจิตใจเบื้องต้นได้ฟรี ทุกที่ ทุกเวลา ปลอดภัย 100% โดยไม่ต้องเปิดเผยตัวตน

## ✨ ฟีเจอร์หลักของ Platform (Core Features)

1. **Anonymous Vent Wall (กำแพงฮีลใจนิรนาม):**
   - เขียนระบายความรู้สึก ปัญหาเรื่องเรียน งาน หรือความสัมพันธ์โดยไม่ต้องระบุชื่อจริง
   - เลือนามแฝงและสัญลักษณ์สัตว์สุดน่ารัก (น้องแมวส้ม, นกฮูกนอนดึก, กระต่ายขี้เซา ฯลฯ)
   - เพื่อนร่วมคอมมูนิตี้สามารถส่งปุ่มกอด `🫂` และส่งพลังใจ `💖` เพื่อเพิ่มความรู้สึกเป็นส่วนหนึ่งและลดความโดดเดี่ยว
   - ระบบตัวกรองคำเสี่ยงและแจ้งเตือนสายด่วนช่วยเหลือฉุกเฉินอัตโนมัติ

2. **Jaidii AI - Active Listening Companion (น้องใจดี ผู้รับฟังด้วยใจ):**
   - แชตบอต AI ที่ออกแบบด้วยหลักจิตวิทยาการรับฟังอย่างเข้าอกเข้าใจ (Empathetic First-Aid)
   - ไม่สั่งสอน ไม่วิพากษ์วิจารณ์ ช่วยสะท้อนความรู้สึก และแนะนำแนวทางจัดการอารมณ์เบื้องต้น
   - มีระบบตรวจจับคำอันตราย (Crisis Intent Detection) เช่น คำที่บ่งชี้การทำร้ายตัวเอง และแสดงคำเตือนพร้อมเบอร์สายด่วนทันที

3. **Daily Mood Tracker & Smart Analytics (เช็กอินและวิเคราะห์อารมณ์):**
   - บันทึกอารมณ์ประจำวัน 5 ระดับ (สดใส, สบายใจ, เฉยๆ, เหนื่อยล้า, เครียด)
   - เลือกปัจจัยที่ส่งผลต่ออารมณ์ (การเรียน, งาน, สุขภาพ, ความสัมพันธ์)
   - กราฟเส้นแนวโน้ม 7 วัน (Chart.js) พร้อม AI Mood Coach สรุปแนวโน้มและให้คำแนะนำแบบเฉพาะบุคคล

4. **Mindful Breathing Space (ฝึกหายใจ 4-7-8 คลายเครียดฉับพลัน):**
   - มินิแอปฝึกสติและกำหนดลมหายใจตามเทคนิค 4-7-8 ที่ได้รับการรับรองทางการแพทย์
   - กราฟิกวงกลมหด-ขยายพร้อมเสียงคลื่นทะเลบำบัด (Web Audio Synthesizer) ช่วยลดอัตราการเต้นของหัวใจ

5. **Official Emergency Directory (รวมสายด่วนและช่องทางช่วยเหลือ):**
   - สายด่วนสุขภาพจิต 1323 (โทรฟรีตลอด 24 ชั่วโมง)
   - สมาคมสะมาริตันส์แห่งประเทศไทย (02-113-6789)
   - แชต LINE @1323forthai และข้อมูลศูนย์แนะแนวมหาวิทยาลัย

## 🤖 การอธิบายขั้นตอนการใช้ AI ในโปรเจกต์ (ตามเกณฑ์ของอาจารย์)

โครงการนี้ใช้ AI เข้ามาเป็นผู้ช่วยในกระบวนการทำงานทั้ง 4 ขั้นตอนอย่างโปร่งใส:

| ลำดับขั้นตอน | รายละเอียดการใช้ AI | เครื่องมือ / วิธีการ |
|---|---|---|
| **1. Ideation & Social Problem Analysis** | วิเคราะห์ Pain Point ของปัญหาสุขภาพจิตวัยรุ่นในไทย สรุปข้อมูลผู้ใช้ (Target Persona) และวางแผน Customer Journey Map | AI ช่วยระดมสมองและสังเคราะห์สถิติสุขภาพจิต |
| **2. System & UI/UX Design** | ออกแบบโครงสร้างข้อมูล, User Flow การระบายความในใจแบบนิรนาม, และการเลือกชุดสีจิตวิทยา (Calming Emerald & Peach) | AI ช่วยจัดทำ Design Specs และ Component Flow |
| **3. Coding & AI Implementation** | • เขียนโค้ดระบบ Frontend (HTML5, Tailwind CSS, JavaScript)<br>• ผสาน AI Engine ในตัวระบบ: สร้างแชตบอต "น้องใจดี" ด้วย Empathetic NLP Rules และ Sentiment Matching เพื่อรับฟังผู้ใช้งานจริง | AI ช่วย Code Generation, Debugging และสร้าง Conversational Engine |
| **4. Pitching & Video Scripting** | เรียบเรียงสคริปต์วิดีโอนำเสนอ 2-3 นาที และโครงสร้าง Slide Presentation ให้ตอบโจทย์ 15 คะแนน | AI ช่วยกลั่นกรองข้อความและจัดลำดับการเล่าเรื่อง (Storytelling) |

## 🚀 วิธีเปิดใช้งานและทดลองใช้งาน Platform

### 1. เปิดทดสอบบนเครื่องตัวเอง (Offline / Local)
- ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดบนเว็บเบราว์เซอร์ (Google Chrome, Edge, Safari) ใช้งานได้ทันที 100% โดยไม่ต้องติดตั้ง Node.js หรือโปรแกรมเพิ่มเติม

### 2. วิธีนำขึ้นออนไลน์เพื่อได้ "Link สำหรับทดลองใช้ Platform" ส่งอาจารย์ (ฟรี & ใช้เวลา 30 วินาที)
สามารถเลือกวิธีที่ง่ายที่สุดได้ดังนี้:

#### วิธีที่ง่ายที่สุด: ผ่าน **Netlify Drop** (ไม่ต้องเขียนคำสั่ง)
1. เข้าเว็บไซต์ [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์โปรเจกต์นี้ทั้งหมด (โฟลเดอร์ที่มี `index.html`, `css`, `js`) ไปวางในกล่องวงกลมบนหน้าเว็บ
3. รอประมาณ 5-10 วินาที ระบบจะสร้างลิงก์เว็บไซต์จริงให้ทันที (เช่น `https://mindspace-healjai.netlify.app`)
4. คัดลอกลิงก์นั้นไปส่งอาจารย์ได้เลย!

#### หรือผ่าน **Vercel** / **GitHub Pages**
- อัปโหลดขึ้น GitHub แล้วเปิดใช้งาน GitHub Pages ในแท็บ Settings -> Pages เลือก Branch `main` โฟลเดอร์ `root`
